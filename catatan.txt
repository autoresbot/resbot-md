Versi 5.3.0

==================================================
1. FIX KONEKSI (paling penting)
==================================================

- Bot tidak reconnect setelah putus
  Dulu status reconnect dipakai bareng oleh sesi utama dan semua jadibot.
  Satu jadibot putus bisa bikin bot utama tidak pernah nyambung lagi.
  Sekarang tiap sesi punya hitungan reconnect sendiri.

- Pesan diproses 2x saat reconnect
  Socket lama baru dibersihkan setelah nunggu 5-30 detik, jadi selama jeda itu
  socket mati masih ikut nangkap pesan. Sekarang dibersihkan lebih dulu.

- Bot mati total kalau reconnect gagal
  Kalau koneksi ulang error (misal internet putus), dulu prosesnya berhenti
  selamanya. Sekarang dicatat di log dan sesi tetap jalan.


==================================================
2. FIX SETTING DESTINATION (group/private/both)
==================================================

- Setting 'private' sekarang benar-benar cuma jalan di chat pribadi
  Dulu pengecekannya kejauhan di bawah, jadi cuma nutup command saja.
  Semua handler tetap aktif di grup, walau sudah disetel 'private':
    - list & respon tetap dibalas
    - antilink tetap hapus pesan & kick
    - autoai / autosimi / autorusuh tetap jawab
    - game tetap dijawab
    - notif ban / AFK / sewa tetap terkirim
    - bot tetap keluar grup otomatis kalau sewa habis
    - welcome & goodbye tetap terkirim

  Sekarang dicek paling awal, jadi bot benar-benar diam di grup.
  Owner tetap bisa pakai bot di mana saja (tidak berubah).
  Setting 'group' dan 'both' tidak berubah sama sekali.


==================================================
3. FIX UPLOAD GAMBAR KE API
==================================================

Masalah:
  Muncul error "Isi file tidak sesuai dengan format yang diizinkan."
  padahal yang dikirim memang gambar.

Penyebab:
  WhatsApp selalu simpan gambar dengan nama .jpg, walaupun isi aslinya
  WebP atau PNG. Waktu diupload, sistem bilang "ini JPEG" tapi isinya bukan,
  jadi server menolak.

Perbaikan:
  Format asli sekarang dideteksi dari isi file, bukan dari nama file.
  - Gambar biasa  -> otomatis dikonversi ke JPEG kalau perlu
  - Sticker/WebP  -> dibiarkan apa adanya (biar fitur convert tetap jalan)

File yang diperbaiki (12 file):
  - plugins/TOOLS/hd.js            (.hd / .remini)
  - plugins/TOOLS/removebg.js      (.rmbg / .removebg / .nobg)
  - plugins/TOOLS/toimg.js         (.toimg)
  - plugins/TOOLS/to url.js        (.tourl)
  - plugins/EDITOR/wanted.js       (.wanted)
  - plugins/EDITOR/wasted.js       (.wasted)
  - plugins/AI/aiimg.js            (.aiimg)
  - plugins/AI/ai image generator.js  (.toanime, .tohijab, dll - 21 command)
  - plugins/MAKER/smeme.js         (.smeme)
  - plugins/MAKER/stickercircle.js (.stickercircle / .scircle)
  - plugins/MAKER/tovid.js         (.tovid / .togif)
  - lib/autoai.js                  (auto AI baca gambar di grup)

Khusus .tourl ada bug tambahan:
  Kalau upload gagal, kodenya balas 'false' lalu langsung dibaca .data.url
  sehingga muncul TypeError dan pesan error asli dari server jadi hilang.
  Sekarang error tampil apa adanya.
