Update Resbot MD 5.4.9


RINGKASAN
=========
- Handler "Mode On" tidak lagi error "Cannot read properties of undefined
  (reading 'DEBUG_ANTIFORWARD')"
- Fitur suara (TTS) seperti .cekodam tidak lagi error "Request path contains
  unescaped characters"
- Log "[SCHEDULE] Membersihkan folder tmp..." tidak lagi muncul di konsol
- .listultah di dalam grup kini HANYA menampilkan ulang tahun anggota grup itu
  (bukan seluruh pengguna bot / global)
- .jadibot mendukung durasi: *.jadibot 628xxxx 7* (aktif 7 hari, lalu stop
  otomatis)
- .brat / .brat2 tidak lagi error "ENOENT ... tmp/sistem/xxxx.webp"
- .tomp3 tidak lagi error "ReferenceError: __dirname is not defined"
- Notifikasi .setpromote / .setdemote kini menampilkan SIAPA pelakunya
  (gunakan variabel @actor, atau otomatis ditambahkan)
- .setopen / .setclose: balasan konfirmasi rapi walau teksnya panjang
- .totalchat kini menghitung chat dengan benar (identitas nomor & LID disatukan)
- Video sambutan (welcome) kini diputar OTOMATIS saat anggota baru masuk
  (mode GIF: berulang & tanpa suara)
- zapo-js otomatis diperbarui ke versi terbaru saat start (rollback otomatis
  bila update bikin bot gagal konek); diatur lewat AUTO_UPDATE_ZAPO di index.js
- Pesan gagal terkirim dengan "negative publish ack ... error=421" kini dicoba
  ulang otomatis (mis. .ping tepat setelah bot connect)


DETAIL
======

[BUG] Mode On Handler - error "Cannot read properties of undefined
      (reading 'DEBUG_ANTIFORWARD')"
File   : handle/MODE ON/handler.js
Sebab  : fungsi handler bernama `process`, membayangi objek global Node
         `process`, sehingga `process.env.DEBUG_ANTIFORWARD` dibaca dari
         fungsi (undefined).
Solusi : fungsi diganti nama menjadi `handleModeOn` (export tetap `process`).


[BUG] TTS .cekodam / fitur suara - "Request path contains unescaped characters"
File   : lib/features.js (textToAudio)
Sebab  : teks dimasukkan langsung ke URL Google TTS tanpa encoding.
Solusi : teks dibungkus encodeURIComponent() sebelum masuk URL.


[UBAH] Log pembersihan tmp tidak lagi ditampilkan
File   : index.js
Solusi : console.log "[SCHEDULE] Membersihkan folder tmp..." dihapus;
         pembersihan tiap 3 jam tetap berjalan.


[UBAH] .listultah per grup (bukan global)
File   : plugins/GROUP/listultah.js
Gejala : di dalam grup, daftar ulang tahun menampilkan semua pengguna bot.
Solusi : saat dijalankan di grup, daftar disaring hanya untuk anggota grup
         tersebut (identitas dicocokkan via nomor telanjang: nomor & LID).


[FITUR] .jadibot dukung durasi (hari)
File   : plugins/OWNER/jadibot.js, lib/jadibot.js, lib/jadibotGuard.js,
         lib/database.js
Gejala : "*.jadibot 628xxxx 7*" sebelumnya menggabungkan angka durasi ke
         nomor sehingga nomor jadi tidak valid.
Solusi : argumen dipisah (nomor + durasi hari). Kedaluwarsa disimpan di kolom
         baru `jadibot.expired_at`. Pengawas berkala (lib/jadibotGuard.js)
         menghentikan jadibot otomatis saat masa aktifnya habis.
         Tanpa durasi -> aktif selamanya (perilaku lama).


[BUG] .brat / .brat2 - "ENOENT ... tmp/sistem/xxxx.webp"
File   : lib/exif.js
Sebab  : os.tmpdir() dialihkan ke ./tmp/sistem (lib/diskGuard.js); folder itu
         bisa belum ada / hilang saat penulisan berkas stiker.
Solusi : folder tmp dipastikan ada (pastikanDirTmp) sebelum setiap penulisan.


[BUG] .tomp3 - "ReferenceError: __dirname is not defined"
File   : plugins/TOOLS/to mp3.js
Sebab  : project ESM tidak punya `__dirname`.
Solusi : berkas sementara ditaruh di folder ./tmp (yang memang dibersihkan
         berkala), bukan `__dirname`.


[FITUR] .setpromote / .setdemote - tampilkan pelaku
File   : lib/participant_update.js, lib/connection.js
Gejala : notifikasi promote/demote hanya menampilkan target, bukan pelakunya.
Solusi : pelaku (author event) diteruskan ke handler. Tersedia variabel baru
         @actor untuk template; bila template belum memuatnya, baris
         "Dipromote/Didemote oleh: @pelaku" ditambahkan otomatis.


[UBAH] .setopen / .setclose - balasan rapi untuk teks panjang
File   : plugins/ADMIN/set open close.js
Solusi : pratinjau teks dirapikan (satu baris, dibingkai, dipotong 300 char).


[BUG] .totalchat - tidak bertambah saat user chat
File   : lib/totalchat.js, plugins/ADMIN/total chat.js
Sebab  : kunci chat tersimpan tidak konsisten (kadang @s.whatsapp.net, kadang
         @lid), sehingga chat orang yang sama terpecah ke beberapa baris dan
         tidak cocok saat ditampilkan.
Solusi : kunci dinormalkan ke nomor telanjang saat disimpan & dijumlahkan;
         saat menampilkan, semua identitas peserta (nomor & LID) disatukan.


[FITUR] Video welcome diputar otomatis
File   : lib/participant_update.js
Gejala : video sambutan harus ditekan dulu untuk diputar.
Solusi : video welcome/left dikirim dengan gifPlayback aktif agar langsung
         jalan. Konsekuensi: diputar berulang & tanpa suara (satu-satunya cara
         WhatsApp memutar video tanpa ditekan).


[FITUR] Auto-update zapo-js + rollback
File   : lib/zapoUpdater.js, index.js
Alasan : zapo-js (koneksi WhatsApp) rilis sangat sering; versi lama bisa
         berhenti konek saat protokol WA berubah.
Cara   : saat start, versi terbaru dicek di npm. Jika lebih baru dan
         AUTO_UPDATE_ZAPO=true (di index.js), versi lama dicatat lalu
         `npm install zapo-js@latest @zapo-js/store-sqlite@latest` dijalankan.
         Setelah koneksi pertama berhasil, penanda dihapus (terverifikasi).
         Jika koneksi gagal, restart berikutnya otomatis rollback ke versi
         lama. Matikan dengan AUTO_UPDATE_ZAPO=false di index.js.


[BUG] Kirim pesan gagal "negative publish ack ... class=message error=421"
File   : lib/zapo/socket.js
Gejala : pesan (mis. .ping) gagal dengan MessagePublishNackError error=421,
         dan log menampilkan error mentah yang membingungkan.
Sebab  : error=421 umumnya karena grup disetel "hanya admin yang boleh kirim"
         (obrolan terbatas) sementara bot BUKAN admin -> server WA menolak
         semua pengiriman bot. Bisa juga penolakan sementara sesaat setelah
         koneksi baru terbentuk.
Solusi : 1) sock.sendMessage mengulang kirim otomatis untuk nack sementara
            (421/420) hingga 3x dengan jeda menaik (aman, pesan belum terkirim
            jadi tidak menimbulkan ganda) — menolong kasus transient;
         2) bila tetap gagal, error mentah diganti pesan yang jelas, mis.:
            "Bot tidak bisa mengirim pesan ke chat ini. Kemungkinan grup
            disetel 'hanya admin yang boleh kirim' sementara bot bukan admin.
            Matikan 'obrolan terbatas' atau jadikan bot admin. (error 421)".
