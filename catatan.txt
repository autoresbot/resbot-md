Update Resbot MD 5.4.4

Baru: config lokal (local.config.js)
- pengaturan khusus komputer sendiri bisa ditulis di local.config.js tanpa
  mengubah config.js. File ini tidak ikut ter-upload ke git
- config.js tetap jadi pengaturan utama; local.config.js hanya mengganti
  bagian yang ditulis di dalamnya
- jika local.config.js tidak ada, bot jalan seperti biasa. Jika isinya
  salah, muncul peringatan [CONFIG] dan bot tetap memakai config.js
- contoh isinya ada di local.config.example.js

Perbaikan Welcome / Left (media GIF)
- sebelumnya welcome dengan media GIF kadang gagal terkirim. Sekarang GIF
  pendek (di bawah 1 detik) tetap bisa dikirim dengan preview
- jika foto/video/GIF welcome gagal dikirim, bot tetap menyapa anggota baru
  dengan teks, tidak diam lagi

Perbaikan .setwelcome / .setleft pakai stiker gerak
- stiker gerak (GIF) tidak lagi gagal dengan pesan "Gagal memproses stiker:
  Bad Request". Penyebabnya konversi selalu lewat API; kalau apikey kosong
  atau API sedang bermasalah, penyimpanan gagal total
- sekarang konversi stiker gerak jadi video dikerjakan langsung di server,
  jadi tidak butuh apikey dan tidak terpengaruh gangguan API
- API hanya dipakai sebagai cadangan bila konversi di server tidak tersedia

Perbaikan .brat dan stiker lainnya (disk penuh / ENOSPC)
- file sementara tidak lagi ditaruh di /tmp panel yang sempit, sekarang di
  folder tmp/sistem milik bot, dan otomatis dibersihkan tiap 15 menit
- jika muncul "no space left on device", bot langsung membersihkan file
  sementara. Jika masih penuh, bot restart sendiri (maksimal 1x per jam,
  tidak akan restart berulang-ulang)
- restart otomatis butuh fitur crash detection di panel (bawaan: aktif)

Perbaikan .upsw (buat story)
- sebelumnya gagal dengan error "direct fanout missing signal sessions".
  Sekarang story teks/foto/video terkirim ke semua pengguna bot
- jika gagal, pesan error ditampilkan lebih jelas

Perbaikan antitagsw
- tag status sekarang dideteksi langsung dari pesan di grup, sehingga
  hapus pesan & peringatan jalan di grup yang benar
- anggota yang hanya membuat story biasa tidak lagi ikut kena peringatan
  atau kick

Autoread untuk story
- jika autoread: true di config, story/status kontak juga otomatis dibaca

.list - menu Pilih List
- setelah daftar list terkirim, bot mengirim tombol "Pilih List". Anggota
  cukup ketuk nama list untuk melihat isinya tanpa perlu mengetik
- isi menu diurutkan abjad mengikuti daftar teks di atasnya
- jika list lebih dari 10, menu otomatis dibagi per 10 baris (maksimal 100
  list; selebihnya tetap bisa dibuka dengan mengetik .list <nomor>)
- jika WhatsApp tidak menampilkan menunya, daftar teks tetap terkirim
  seperti biasa

Perbaikan .list - isi yang terbuka salah
- list yang namanya terkandung di nama list lain tidak lagi membuka isi yang
  keliru. Contoh: dengan list "bot" dan "robot", memilih "bot" dulu
  menampilkan isi "robot"
- nomor pada .list <nomor> sekarang mengikuti urutan yang tampil di layar
  (urut abjad). Sebelumnya nomor memakai urutan penyimpanan, padahal daftar
  yang tampil sudah diurutkan, jadi nomor di layar bisa membuka list lain

.status lebih lengkap
- sekarang menampilkan: mode bot (public/self), APIKEY terisi atau kosong,
  grup ini sudah di-acc atau belum, jumlah grup di-acc, autoread, anti call,
  auto backup, selalu online, uptime, dan pemakaian RAM
